# DUALITY

Персональное портфолио с двумя реальностями: современный светлый сайт и художественный архив старого интернета. React 19, TypeScript, Vite, обычный CSS. Без платных сервисов, базы данных, авторизации, внешних шрифтов и медиа.

## Локальная разработка

Требуется Node.js 22.12+ (проверено на Node 24) и npm.

```sh
npm ci
npm run dev
```

Сервер слушает `0.0.0.0:5173`. `npm run typecheck` проверяет TypeScript, `npm run build` создаёт `dist`, `npm run preview` запускает собранную версию. Если домашний npm-кэш недоступен, используйте `npm ci --cache /tmp/duality-npm-cache`.

## Данные и структура

- `src/data.ts` — имя, описание, контакты, навыки, проекты и услуги. Перед персональной публикацией замените «Ваше имя», биографию и заполните `email`. Пока email пуст, не показывается неработающая кнопка связи. Описания услуг — редактируемое предложение, а не заявление о коммерческом опыте.
- `src/components/Welcome.tsx` — старт и скрытый квадрат с областью нажатия 48×48 px.
- `Portfolio.tsx` — шесть разделов профессионального портфолио.
- `Game.tsx` — исследование трёх файлов и терминал допуска.
- `Archive.tsx` — пять разделов архива, треды, история и дополнительная загадка.
- `src/state.ts` — проверка ответов и безопасное сохранение прогресса.
- `src/styles.css` — адаптивные стили, локальные CSS-иллюстрации и уменьшение анимаций.

CUT CULTURE открывается по существующему адресу https://cut-culture.vercel.app/ — его репозиторий не затрагивается. Иллюстрация карточки — авторская типографическая композиция, не скриншот проекта. Все мистические персонажи, даты и события вымышлены; пояснение находится в `/about/` архива.

## Прохождение (спойлеры)

На стартовом экране нажмите маленький квадрат внизу. Откройте README, журнал и изображение. Ключ: `ECHO-04-17`, регистр не важен. README объясняет порядок и дефисы, журнал выделяет месяц, изображение — канал. Таймера нет: чтение рассчитано примерно на 1–2 минуты, но игрок не ограничен. Ошибочный ответ можно исправить без потери прогресса. После первого прохождения архив открывается напрямую через квадрат или ссылку в футере обычного портфолио.

В архиве откройте `/files/` → `AFTER.TXT`. Первые буквы четырёх строк дают `STAY`. Это открывает дополнительную финальную запись. Клик по №000 в боковой панели показывает ещё одно сообщение.

Текущий режим, допуск и находка хранятся в `localStorage` под ключом `duality.v1`. При недоступном хранилище приложение продолжает работать до перезагрузки. Настройки архива позволяют повторить входную игру и уменьшить анимации. Системный `prefers-reduced-motion` также поддержан. «Завершить сеанс» всегда возвращает в обычное портфолио. Локальный ключ не является механизмом безопасности: архив — часть публичного сайта.

## Автоматические браузерные проверки

```sh
npx playwright install --with-deps chromium
npm test
```

При наличии системного Chromium без скачивания браузера:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm test -- --workers=3
```

Тесты запускаются на размерах Desktop Chrome, iPhone 13 и Pixel 7 в Chromium: переходы, документы, неверный и верный ключ, загадка архива, сохранение, повтор игры, уменьшение анимаций, работа без localStorage, отсутствие горизонтального переполнения. Это эмуляция размеров и touch, не проверка на физическом iPhone/Safari.

## Vercel

Проект готов для Vercel: импортируйте `Emoculture/duality-portfolio`, выберите ветку `main`, корневой каталог репозитория. Preset: Vite; build: `npm run build`; output: `dist`; install: `npm ci`. Эти параметры также заданы в `vercel.json`. Переменные окружения не требуются. Production branch — `main`; существующая Git-интеграция, если подключена владельцем, сможет разворачивать изменения после push. Фактическую публикацию подтверждает успешный deployment в Vercel, а не наличие конфигурации.

## Облачная среда

Используйте существующий checkout `/workspace/duality-portfolio`, без создания worktree. Установка: `npm ci --cache /tmp/duality-npm-cache`. Процессы не сохраняются между задачами: запускайте `npm run dev` заново. Проверка готовности — HTTP-ответ страницы и выполнение браузерных тестов, а не только открытый порт.
