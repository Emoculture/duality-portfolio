# DUALITY

Персональное портфолио с двумя реальностями: современный светлый сайт и художественный архив старого интернета. React 19, TypeScript, Vite, обычный CSS. Без платных сервисов, базы данных, авторизации, внешних шрифтов и медиа.

## Локальная разработка

Требуется Node.js 22.12+ (проверено на Node 24) и npm.

```sh
npm ci
npm run dev
```

Сервер слушает `0.0.0.0:5173`. `npm run typecheck` проверяет TypeScript, `npm run build` создаёт `dist`, `npm run preview` запускает собранную версию. Если домашний npm-кэш недоступен, используйте `npm ci --cache /tmp/duality-npm-cache`.

## Данные и структура

- `src/data.ts` — имя, описание, контакты, навыки, проекты и услуги. Перед персональной публикацией замените «Ваше имя», биографию и заполните `email`. Пока email пуст, не показывается неработающая кнопка связи. Описания услуг — редактируемое предложение, а не заявление о коммерческом опыте.
- `src/components/Welcome.tsx` — старт и скрытый квадрат с областью нажатия 48×48 px.
- `Portfolio.tsx` — шесть разделов профессионального портфолио.
- `Game.tsx` — исследование трёх файлов и терминал допуска.
- `Archive.tsx` — главная имиджборда, шесть досок, файлы, история и дополнительная загадка.
- `ArchiveThreads.tsx`, `ArchiveImage.tsx` — анонимные треды, перекрёстные цитаты и доступный просмотр снимков.
- `src/archiveData.ts`, `src/archive.css`, `public/archive/` — данные обсуждений, изолированные стили имиджборда и авторские SVG-иллюстрации.
- `src/state.ts` — проверка ответов и безопасное сохранение прогресса.
- `src/styles.css` — адаптивные стили, локальные CSS-иллюстрации и уменьшение анимаций.

CUT CULTURE открывается по существующему адресу https://cut-culture.vercel.app/ — его репозиторий не затрагивается. Иллюстрация карточки — авторская типографическая композиция, не скриншот проекта. Все мистические персонажи, даты и события вымышлены; пояснение находится в `/about/` архива.

## Прохождение (спойлеры)

На стартовом экране нажмите маленький квадрат внизу. Откройте README, журнал и изображение. Ключ: `ECHO-04-17`, регистр не важен. README объясняет порядок и дефисы, журнал выделяет месяц, изображение — канал. Таймера нет: чтение рассчитано примерно на 1–2 минуты, но игрок не ограничен. Ошибочный ответ можно исправить без потери прогресса. После первого прохождения архив открывается напрямую через квадрат или ссылку в футере обычного портфолио.

В архиве откройте `/files/` → `AFTER.TXT`. Первые буквы четырёх строк дают `STAY`. Это открывает дополнительную финальную запись. На главной выберите доску `/000/`; клик по №000 показывает ещё одно сообщение. Доска `/log/` содержит исчезнувшую запись №017, а заголовки страницы №000 ведут к оставшемуся файлу. Цитаты `>>1273` переключают тред и переводят фокус на нужное сообщение. Снимки открываются в диалоге и закрываются по Escape с возвратом фокуса.

Текущий режим, допуск и находка хранятся в `localStorage` под ключом `duality.v1`. При недоступном хранилище приложение продолжает работать до перезагрузки. Настройки архива позволяют повторить входную игру и уменьшить анимации. Системный `prefers-reduced-motion` также поддержан. «Завершить сеанс» всегда возвращает в обычное портфолио. Локальный ключ не является механизмом безопасности: архив — часть публичного сайта.

## Автоматические браузерные проверки

```sh
npx playwright install --with-deps chromium
npm test
```

При наличии системного Chromium без скачивания браузера:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm test -- --workers=3
```

Тесты запускаются на размерах Desktop Chrome, iPhone 13 и Pixel 7 в Chromium: переходы, документы, неверный и верный ключ, загадка архива, сохранение, повтор игры, уменьшение анимаций, работа без localStorage, отсутствие горизонтального переполнения. Дополнительные сценарии проверяют все доски, классическую палитру, перекрёстные цитаты, просмотр снимков и скрытые записи. Это эмуляция размеров и touch, не проверка на физическом iPhone/Safari.

## Vercel

Проект готов для Vercel: импортируйте `Emoculture/duality-portfolio`, выберите ветку `main`, корневой каталог репозитория. Preset: Vite; build: `npm run build`; output: `dist`; install: `npm ci`. Эти параметры также заданы в `vercel.json`. Переменные окружения не требуются. Production branch — `main`; существующая Git-интеграция, если подключена владельцем, сможет разворачивать изменения после push. Фактическую публикацию подтверждает успешный deployment в Vercel, а не наличие конфигурации.

## Облачная среда

Используйте существующий checkout `/workspace/duality-portfolio`, без создания worktree. Установка: `npm ci --cache /tmp/duality-npm-cache`. Процессы не сохраняются между задачами: запускайте `npm run dev` заново. Проверка готовности — HTTP-ответ страницы и выполнение браузерных тестов, а не только открытый порт.

## THE USER WHO NEVER LEFT

В архиве ссылка `INVESTIGATION.TXT` открывает пять глав с шестью последовательными задачами. Подсказки и журнал доступны на странице; прогресс хранится отдельно под ключом `duality.investigation.v1`, поэтому старые сохранения `duality.v1` не затрагиваются. Кнопка в журнале сбрасывает только расследование. При недоступном localStorage прогресс действует в текущем сеансе.

Проекты поддерживаются вручную в `src/data.ts`; каталог основан на публичном профиле GitHub и README. Автоматический импорт и актуализация дат ещё не реализованы.

## Оболочка архива

ARCHIVE оформлен как окно Internet Explorer: навигация «Назад» и «Вперёд» работает в пределах текущего сеанса, «Домой» открывает главную, поиск фильтрует каталог проектов. Кнопка закрытия возвращает в обычное портфолио. Строка меню декоративна. Локальные файлы `public/archive/user-000.png` и `corridor.png` — оригинальные изображения для вымышленной истории; остальные иллюстрации также хранятся локально.

## INCIDENT 000

Из ARCHIVE откройте `INCIDENT_000.TXT` или файл `SYSTEM_RECOVERY.EXE`. Семь целей доступны в журнале расследования; разделы `/recovery/`, `/cctv/`, `/system/`, `/history/` и `/audio/` переключаются внутри архива и включены в его историю «Назад/Вперёд». Адресная строка Internet Explorer — часть художественного интерфейса, а не отдельный сетевой сервис.

Восстановите изображение и найдите кадр CAM_03 в 00:01, чтобы открыть виртуальную ОС. Команда `help` перечисляет команды; `cd USERS`, `type ADMIN_NOTES.TXT` и `unlock 000-0102` открывают следующую главу. Финальный ключ собирается из последней аудиозаписи и времени камеры; у загадок есть подсказки. Все три решения доступны после прохождения глав. PURGE меняет только игровой интерфейс и не удаляет реальные файлы; после любого финала можно начать заново и сохранить список открытых концовок.

`duality.incident.v1` — отдельное версионированное сохранение. При первом открытии из `duality.v1` и `duality.investigation.v1` считывается информация о прежнем прогрессе, а старые ключи не удаляются. Сброс INCIDENT требует подтверждения и сохраняет журнал концовок. При запрете localStorage прогресс доступен до закрытия или перезагрузки вкладки. Терминал работает только с виртуальными строками в `src/incident/files.ts` и не выполняет команды операционной системы.

Камеры показывают неподвижные архивные кадры, а не видео. Иллюстрации камер и пять коротких записей созданы локально; голоса синтезированы, расшифровки доступны рядом с аудиоплеерами, звук не запускается автоматически. Все даты, сообщения и персонажи INCIDENT — художественный вымысел. Существующее изображение пользователя №000 не изменялось.
